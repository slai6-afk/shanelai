
  # Designer Portfolio Website

  This is a code bundle for Designer Portfolio Website. The original project is available at https://www.figma.com/design/RKTqjNdk8v2knPBOgQjICo/Designer-Portfolio-Website.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  ## Viewing the homepage visually

  1. After `npm run dev` prints the local address (for example `http://localhost:5173`), open that URL in your browser.
  2. To preview the mobile layout, set your browser to a mobile viewport (e.g., 390 × 844) using DevTools' responsive mode.
  3. You can also run `npm run build` followed by `npm run preview` if you prefer to check the production build.
